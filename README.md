# Offensive Security – My Learning Journey

Welcome to my Offensive Security learning repository.

This repository documents my 12-month journey from beginner to Red Team and Offensive Security practitioner.

## Learning Goals

- Master Linux fundamentals.
- Understand computer networking.
- Learn Python and Bash scripting.
- Develop reconnaissance skills.
- Understand web application security.
- Practice penetration testing.
- Learn privilege escalation.
- Understand Active Directory security.
- Learn Red Team operations.
- Practice adversary emulation.
- Develop Purple Team skills.
